# Jee Saa — Shree Durga Textiles

Static, mobile-first wholesale textile website for GitHub Pages.

## Before deployment
1. Replace `YOUR-DOMAIN.example` in `sitemap.xml` and `robots.txt` with the final domain.
2. Add the final canonical URL to the `url` field in the Organization JSON-LD inside `index.html`.
3. Replace the footer developer WhatsApp placeholder `91XXXXXXXXXX` in `index.html` with the developer's actual WhatsApp number.
4. Keep the five supplied source assets in `/assets/`.

## Files
- `index.html` — single-page site, SEO metadata, JSON-LD, content and WhatsApp CTAs.
- `styles.css` — responsive mobile-first styling.
- `script.js` — lightweight shade-card image viewer.
- `assets/` — optimized WebP versions plus supplied JPEG originals.
- `robots.txt` and `sitemap.xml` — deployment SEO files.
